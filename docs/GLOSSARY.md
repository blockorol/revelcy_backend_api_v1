# Glossary

- Premarket: main launch/trading-related domain object.
- Concept: draft or early premarket data, including visibility behavior.
- Holder: user entry or position in a premarket.
- Claim: token claim behavior after required conditions are met.
- Vesting: scheduled token withdrawal behavior.
- Whitelist: allowlist and approval/rejection flow for premarket participation.
- Community: token/community metadata associated with a premarket.
- Availability: fields and rules controlling premarket availability.
- Finish: lifecycle action that finalizes a premarket.
- Kill: lifecycle action that cancels/kills a premarket.
- Out: lifecycle action where a holder exits a premarket.
- Extend: lifecycle action that extends a deadline.
- API model: external HTTP request/response model in `src/api`.
- Internal model: service/domain model in `src/models`.
- Storage model: database row/query model in `src/storage`.
